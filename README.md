# POPADANEC: REBORN

Полная переработка Popadanec: один HTML-файл, 12 регионов, новая боевая система, крафт, дерево навыков, перенос старых сохранений (popad_save3).

## Играть / скачать

- Открыть: https://bilijmiroslav87-droid.github.io/popadanec/popadanec_reborn.html
- Скачать файл: https://raw.githubusercontent.com/bilijmiroslav87-droid/popadanec/main/popadanec_reborn.html

## Управление

ПК: WASD — движение, J — атака, K — тяжёлая, L/ПКМ — блок, Shift — перекат, E — способность, Q — зелье, Space — действие, Tab — инвентарь, M — регионы, Esc — пауза.

Телефон: стик слева, кнопки справа. Прогресс хранится в браузере.
